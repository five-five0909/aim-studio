# 🎬 AI 漫剧/连续剧创作工作流设计 Prompt

> **角色**：你是一个 AI 漫剧创作工作流架构师，需要设计一个从「文字剧本」到「AI 漫剧/连续剧成片」的完整创作流水线。该流水线将作为 Skill 注入 Claude Code，让 Claude 成为漫剧创作助手。

---

## 一、创作流水线总览

```
剧本输入 → 剧本解析 → 角色建档 → 分镜设计 → 提示词生成 → 图片/视频生成 → 产出组织
  ↓          ↓          ↓          ↓           ↓              ↓              ↓
 .md      结构化       角色卡     分镜表    image/video     调用API       按集归档
 文件      JSON        .md       .md       prompts        或手动生成      输出
```

### 核心原则
1. **角色一致性优先** — 同一角色在不同画面中必须具有可辨认的一致外观
2. **风格锁定** — 全剧画风/色调/渲染风格统一，不可漂移
3. **叙事连贯** — 画面之间有明确的叙事逻辑和时间线
4. **模态分离** — 图片提示词和视频提示词使用各自独立的优化 Skill
5. **可追溯** — 每张图/每段视频都可追溯其原始剧本场景和分镜编号

---

## 二、Step 1 — 剧本解析 Skill (`script-parser.md`)

### 输入
用户以 Markdown 格式编写的剧本，可以是：
- 自由格式文字描述
- 分场景格式
- 对话脚本
- 简要故事大纲

### 输出
结构化场景列表（JSON + Markdown）：

```json
{
  "title": "剧集名称",
  "episode": 1,
  "totalScenes": 8,
  "scenes": [
    {
      "id": "S01",
      "title": "场景标题",
      "location": "地点描述",
      "time": "时间（如：傍晚/深夜/清晨）",
      "weather": "天气/氛围",
      "characters": ["角色A", "角色B"],
      "action": "场景动作描述",
      "dialogue": [
        {"speaker": "角色A", "line": "台词内容", "emotion": "情绪"},
        {"speaker": "角色B", "line": "台词内容", "emotion": "情绪"}
      ],
      "narrative": "旁白/叙述",
      "mood": "情绪基调",
      "visualHint": "画面暗示（导演提示）"
    }
  ]
}
```

### 解析规则
1. **智能分场** — 根据地点/时间/人物切换自动拆分场景
2. **情绪推断** — 从对话和叙述中推断角色情绪（用于后续表情控制）
3. **时间线排序** — 确保场景按叙事时间排列
4. **画面暗示提取** — 将文本中的视觉化描写提取为 `visualHint`
5. **角色识别** — 自动提取所有出场角色，建议建档

## 三、Step 2 — 角色一致性管理 Skill (`character-manager.md`)

### 角色卡格式

```markdown
# 角色卡 — [角色名]

## 基础信息
- **姓名**：
- **性别**：
- **年龄**：
- **身高体型**：

## 外观特征（核心锚点 — 每张图必须固定）
- **发型/发色**：（如：黑色齐肩短发，左侧有一缕染紫挑染）
- **肤色**：
- **面部特征**：（如：圆脸，双眼皮，小巧鼻翼，嘴角有一颗痣）
- **瞳色**：
- **体型轮廓**：

## 服装系统
- **主要服装**：（日常/默认穿着的详细描述）
- **备选服装1**：（场景切换时可用）
- **配饰**：（始终携带的物品/饰品）

## 表情映射表
| 情绪 | 面部描述 | 身体语言 |
| --- | --- | --- |
| 开心 | 嘴角上扬露齿，眼角弯成月牙 | 身体微微前倾 |
| 悲伤 | 嘴角下垂，眉心微蹙 | 肩膀下沉，目光低垂 |
| 愤怒 | 双眉紧锁，嘴唇紧抿 | 下巴微抬，双拳握紧 |
| 惊讶 | 嘴巴微张，眉毛上挑 | 后仰，双手抬起 |
| 忧虑 | 眉头轻皱，嘴唇微咬 | 手指交叉或摩挲 |

## 画风适配参考词
- **写实风**：[具体面部描写，参考真人五官比例]
- **二次元/动漫风**：[大眼、简化面部特征、头发色块]
- **美漫/3D风**：[高光/阴影分明，材质感强]

## Negative Prompt 锚点
（列出该角色绝对不应出现的特征，避免 AI 漂移）
- 不应出现：[金发、长发、胡须、纹身... 等与设定矛盾的项]
```

### 一致性注入策略
1. **每次生成图片/视频提示词时**，自动从角色卡中提取「外观特征」段落注入
2. **使用角色 ID 引用** — 提示词中不写"一个女孩"，而是注入完整角色卡特征
3. **跨集继承** — 角色卡在整个项目中共享，不随集数重建
4. **表情映射自动触发** — 根据剧本中的 `emotion` 字段自动查表注入对应面部/身体描写

## 四、Step 3 — 分镜设计 Skill (`storyboard-designer.md`)

### 分镜表格式

```markdown
# 分镜表 — 第X集

| 镜号 | 场景ID | 景别 | 镜头运动 | 画面内容 | 角色 | 表情/动作 | 对白/旁白 | 时长(s) | 生成类型 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 001 | S01 | 远景 | 固定 | 黄昏小镇全貌 | 无 | — | [旁白]... | 3 | 图片 |
| 002 | S01 | 中景 | dolly in | 角色A 走入画面 | 角色A | 忧虑 | — | 5 | 视频 |
| 003 | S01 | 特写 | 固定 | 角色A 面部 | 角色A | 悲伤 | "..." | 3 | 视频 |
```

### 分镜设计规则
1. **景别节奏** — 遵循「远 → 中 → 近 → 特写」或反向的节奏切换规律
2. **对话镜头** — 对话场景使用正反打（A 说话 → A 特写，B 回答 → B 特写）
3. **情绪镜头** — 关键情绪转折使用 slow dolly in 到面部特写
4. **环境镜头** — 每个新场景以空镜头/环境镜头建立场景
5. **生成类型决策**：
   - 静态场景/环境/肖像 → 图片
   - 含动作/镜头运动/对话 → 视频
   - 特写表情变化 → 视频（利用口型同步）
6. **时长估算** — 图片类默认 3s（后期可做 Ken Burns 效果），视频 3-8s

## 五、Step 4 — 提示词生成器

### 图片提示词生成（调用 `image-prompt-optimizer.md` Skill）

将分镜表中 `生成类型=图片` 的行，结合角色卡和风格卡，按照图片生成优化 Skill 的规则生成结构化提示词。

**自动注入流程**：
```
分镜行 + 角色卡(外观特征) + 风格卡(全局画风) + 表情映射表(当前情绪)
    ↓
图片生成优化 Skill 处理
    ↓
结构化输出：[任务类型] [主体描述] [空间布局] [文本内容] [背景] [光照] [风格]
```

### 视频提示词生成（调用 `video-prompt-optimizer.md` Skill）

将分镜表中 `生成类型=视频` 的行，结合角色卡和风格卡，按照视频生成优化 Skill 的规则生成六段式提示词。

**自动注入流程**：
```
分镜行 + 角色卡(外观特征+表情映射) + 风格卡(画风+影调) + 对白
    ↓
视频生成优化 Skill 处理
    ↓
六段式输出：[语境] [视觉] [对话] [音效] [音乐] [风格]
```

## 六、Step 5 — 风格统一 Skill (`style-keeper.md`)

### 风格卡格式

```markdown
# 全局风格定义

## 画风
- **风格类型**：（如：赛博朋克/水墨中国风/日系动漫/美式漫画/写实摄影）
- **画风参考**：（参考作品，如：新海诚/蜘蛛侠平行宇宙/攻壳机动队）
- **渲染质感**：（如：2D 平涂/3D 渲染/水彩质感/油画笔触）

## 色彩方案
- **主色调**：（如：深蓝+霓虹紫+赛博青）
- **辅助色**：
- **高光色**：
- **阴影色**：
- **色彩情绪映射**：
  - 欢快场景 → 暖色调，饱和度 +20%
  - 紧张场景 → 冷色调，对比度 +30%
  - 悲伤场景 → 灰调，降饱和度

## 光影
- **主光源**：（如：侧光/逆光/环境光/霓虹灯光）
- **影调**：（高调/低调/高对比度）
- **特殊光效**：（如：体积光/镜头光晕/雨滴折射）

## 场景模板
- **室内场景**：（默认光照/色彩/装饰风格）
- **室外日景**：
- **室外夜景**：

## 文本排版（若有字幕/旁白叠加）
- **字体风格**：
- **字幕位置**：
- **对话气泡样式**：（漫画专用）

## 强制锁定词（每个提示词必须包含）
- `[画风锁定词列表，如: cyberpunk aesthetic, neon glow, dark atmosphere]`

## 禁止词（Negative Prompt 全局）
- `[全局禁止词，如: photorealistic, watermark, text overlay, low quality]`
```

### 风格注入策略
1. **强制锁定词** — 每个图片/视频提示词末尾必须追加风格锁定词
2. **禁止词** — 每个提示词的 negative prompt 必须包含全局禁止词
3. **色彩情绪自动适配** — 根据场景 mood 自动调整色彩方案
4. **跨集一致** — 风格卡在项目级别定义，所有集数共享

## 七、Step 6 — 集数管理 Skill (`episode-manager.md`)

### 项目目录结构

```
.aim-studio/
├── project.yaml              # 项目元数据
├── characters/                # 角色卡（全局共享）
│   ├── 主角A.md
│   ├── 配角B.md
│   └── _index.md             # 角色索引
├── style/
│   └── global-style.md       # 全局风格卡
├── episodes/
│   ├── ep01/
│   │   ├── script.md          # 第1集剧本
│   │   ├── scenes.json        # 解析后的结构化场景
│   │   ├── storyboard.md      # 分镜表
│   │   ├── prompts/
│   │   │   ├── 001-远景-黄昏小镇.txt     # 图片提示词
│   │   │   ├── 002-中景-角色A走入.txt     # 视频提示词
│   │   │   └── ...
│   │   └── output/
│   │       ├── 001.png
│   │       ├── 002.mp4
│   │       └── ...
│   ├── ep02/
│   │   └── ...
│   └── _overview.md           # 集数总览/进度跟踪
└── workflow.md                # 工作流指南
```

### project.yaml 模板

```yaml
name: "我的赛博漫剧"
type: "漫剧"          # 漫剧 / 连续剧 / 绘本
style: "赛博朋克"
total_episodes: 12
status: "制作中"
created: "2026-02-12"
models:
  image: "qwen-image"        # 或 flux / midjourney / dall-e
  video: "seedance"          # 或 kling / runway / pika
resolution:
  width: 1920
  height: 1080
aspect_ratio: "16:9"
```

### 集数管理规则
1. **编号规范** — `ep01` / `ep02` / ... 严格递增
2. **提示词命名** — `{镜号}-{景别}-{简述}.txt`
3. **输出命名** — `{镜号}.{png|mp4}`
4. **进度跟踪** — 在 `_overview.md` 中标记每集状态（剧本✅ / 分镜✅ / 提示词✅ / 生成中🔄 / 完成✅）
5. **角色出场统计** — 自动统计每个角色在各集的出场次数

## 八、Slash 命令设计

| 命令 | 功能 | 输入 | 输出 |
| --- | --- | --- | --- |
| `/aim:new-project` | 初始化新漫剧项目 | 项目名/类型/风格 | 生成目录结构 + 项目模板 |
| `/aim:new-episode` | 新建一集 | 集数编号 | 生成该集目录 + 模板文件 |

| `/aim:prompts:video` | 单独生成视频提示词 | 分镜行 | 单条视频提示词 |
| `/aim:status` | 查看项目进度 | 无 | 显示进度概览 |
| `/aim:export` | 导出提示词清单 | 集数范围 | 汇总输出 |

## 九、工作流示例

### 完整创作流程

```
用户: /aim:new-project
→ 创建项目目录，填写 project.yaml

用户: /aim:new-character
→ 逐一创建角色卡

用户: 编写第1集剧本 → episodes/ep01/script.md

用户: /aim:parse-script episodes/ep01/script.md
→ 生成 scenes.json（结构化场景列表）

用户: /aim:storyboard episodes/ep01/scenes.json
→ 生成 storyboard.md（分镜表）

用户: （审阅/调整分镜表）

用户: /aim:prompts episodes/ep01/storyboard.md
→ 批量生成所有提示词到 prompts/ 目录

用户: （复制提示词到 Qwen-Image/Seedance 等 AI 生成工具）

用户: （将生成结果存入 output/ 目录）

用户: /aim:status
→ 查看当前进度
```

## 十、质量控制清单

- [ ] 每个角色在所有镜头中外观描述是否一致？
- [ ] 风格锁定词是否出现在每个提示词中？
- [ ] 禁止词是否出现在每个 negative prompt 中？
- [ ] 场景之间是否有镜头过渡逻辑？
- [ ] 时间线是否连贯（日→夜 不可跳跃无标记）？
- [ ] 是否所有对话场景都有对应的视频提示词？
- [ ] 图片/视频的分辨率/宽高比是否统一？
