# 剧情检查

检查当前剧本与设定的一致性，发现并修正潜在问题。

## 检查维度

### 角色一致性
- [ ] 对白风格是否符合角色设定
- [ ] 行为决策是否符合性格逻辑
- [ ] 外貌描述是否一致
- [ ] 能力表现是否在设定范围内
- [ ] 角色成长是否合理（长篇故事）

### 剧情连贯性
- [ ] 时间线是否合理
- [ ] 前后事件是否矛盾
- [ ] 伏笔是否有遗漏
- [ ] 章节衔接是否流畅

### 设定一致性
- [ ] 是否与世界观冲突
- [ ] 力量体系是否一致
- [ ] 场景描述是否一致

### 视频格式检查（如适用）
- [ ] 单场时长是否符合配置
- [ ] 每集场次数是否合理
- [ ] 视频总时长是否在预期范围

## 执行方式

直接执行检查：
1. 读取当前剧集内容
2. 读取 `.aim-studio/spec/story/` 下的设定文件（character.md, world.md）
3. 按上述维度逐项检查
4. 输出检查报告

## 输出格式

```markdown
## 检查报告

### 发现问题
| 类型 | 位置 | 问题描述 | 严重程度 | 修改建议 |
|------|------|----------|----------|----------|
| 角色一致性 | EP03场次2 | 主角对白风格突变 | 中 | 调整为... |

### 通过项
- ✅ 时间线合理
- ✅ 世界观无冲突

### 建议优化
- （可选的优化建议）
```
