# 完成工作

完成当前创作任务后，进行最终检查并记录工作内容。

---

## 适用场景

- 完成一集剧本创作
- 完成一个场次的创作
- 结束创作会话

---

## 检查清单

### 1. 内容完整性

- [ ] 剧本内容是否完整
- [ ] Seedance 2.0 六要素是否齐全
- [ ] 角色行为是否符合人设
- [ ] 剧情逻辑是否连贯

### 2. 格式检查

- [ ] 文件格式是否符合规范
- [ ] 命名是否一致
- [ ] 段落划分是否合理

### 3. 质量检查

- [ ] 是否有明显的逻辑错误
- [ ] 角色对话是否自然
- [ ] 场景描述是否清晰

### 4. 相关文件更新

- [ ] 是否需要更新角色设定 (character.md)
- [ ] 是否需要更新世界观设定 (world.md)
- [ ] 是否需要添加新角色

---

## 执行步骤

### 步骤 1：自我检查

按照上述清单逐项检查。

### 步骤 2：可选检查

如果需要更深入的检查：

```
/aim:check-story
```

### 步骤 3：记录工作

使用记录命令保存本次工作内容：

```bash
python3 ./.aim-studio/scripts/add_session.py --title "<工作标题>" --summary "<工作摘要>"
```

### 步骤 4：报告完成

向用户报告完成的内容和下一步建议。

---

## 组合使用方案

### 完整工作流程

```
1. 创作中...
2. /aim:check-story       → 检查剧情一致性
3. 修改问题...
4. /aim:finish-work       → 完成工作
5. /aim:record-session    → 记录工作内容
```

### 快速完成流程

```
1. 创作中...
2. /aim:finish-work       → 快速完成检查
```

---

## 相关命令

| 命令 | 用途 |
|------|------|
| `/aim:check-story` | 检查剧情一致性 |
| `/aim:record-session` | 记录工作内容 |
| `/aim:start` | 开始新会话 |
