## 视觉一致性检查表

### 角色外观锁定

在创作每个场次时，必须检查以下一致性：

- [ ] 发型一致
- [ ] 服装一致
- [ ] 体型一致
- [ ] 标志性特征出现
- [ ] 声音特征描述正确

### 角色参考图

建议为每个主要角色生成参考图：

```
【角色参考图提示词】
风格：xianxia, chinese fantasy, character design
主体：{角色名称}，{外观描述}

表情：中性表情
场景：纯色背景
光线：柔和的正面光

```

## 角色声音设计（Seedance 2.0）

| 少年音 | 清亮、清澈、稚嫩 |

| 中年音 | 沉稳、浑厚、沧桑 |
| 老年音 | 沙哑、低沉、缓慢 |
| 女高音 | 清脆、明亮、甜美 |
| 女中音 | 温柔、圆润、知性 |
| 女低音 | 低沉、磁性、成熟 |

| 语调类型 | 描述词 |

| 慵懒 | 漫不经心、懒散、随意 |

## 示例：完整角色档案

```markdown
## 角色名称：沈安在

### 基础信息
- **年龄**：约40岁
- **性别**：男
- **身份**：青云峰峰主
- **阵营**：正道

### 外观特征
- **身高**：约180cm
- **体型**：修长挺拔
- **发型**：长发束起
- **发色**：黑发，两鬓霜白
- **瞳色**：深邃黑瞳
- **肤色**：白皙
- **标志性特征**：两鬓霜白，面容俊俏

### 服装设定
- **常服**：白色长袍，衣袂飘动
- **战斗服**：同常服
- **配饰**：无

### 声音特征（Seedance 2.0）
- **音色**：沉稳有力的男中音
- **语调**：故作高深时冷淡，内心独白时轻快
- **方言口音**：普通话，带有仙风道骨的从容感
- **口头禅**："不过是些微末伎俩"

### 性格特点
- **外在**：高深莫测、庄严威严
- **内在**：腹黑、护短、爱演
- **系统**：乖徒儿养成系统宿主

### 成长轨迹
| 章节 | 状态 | 能力变化 | 心理变化 | 关键事件 |
|------|------|----------|----------|----------|
| 第1集 | 初始 | 系统激活 | 慵懒→热血 | 挽留徒弟 |
| 第2集 | 成长 | 展示剑法 | 紧张→从容 | 传授剑法 |
```
