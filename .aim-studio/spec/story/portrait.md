# 角色肖像规范

> 用于生成一致的角色肖像图片，确保跨场次的角色形象统一（Qwen-Image 优化）

---

## Qwen-Image 核心优势

| 能力维度 | 技术特点 | 优势 |
|---------|---------|------|
| **复杂文本渲染** | 中英文多行文本、段落级语义 | 中文渲染 58.30%，远超竞品 |
| **精准图像编辑** | 语义一致性与视觉保真度 | 支持链式编辑 |
| **身份一致性** | MSRoPE 位置编码 | 多角度保持身份一致 |

## Prompt 结构原则

Qwen-Image 使用 **Qwen2.5-VL 作为文本编码器**，最优 Prompt 应包含：

```
【主体对象】+ 【属性细节（颜色/数量/形状/材质）】+ 【空间关系】+ 【环境背景】+ 【风格/光影】
```

## 中文场景特化技巧

### 1. 直接使用中文字符

```
✅ "招牌上写着'云计算'"
❌ "sign with Chinese characters meaning cloud computing"
```

### 2. 利用成语、诗句、对联

```
一首古诗书法作品，内容为：
"毕竟西湖六月中，风光不与四时同。
接天莲叶无穷碧，映日荷花别样红。"
字体为楷书，背景是水墨画风格的西湖景色。
```

### 3. 具体描述面部特征

```
✅ "棱角分明的国字脸，深邃的黑色丹凤眼，剑眉英气"
❌ "帅气的脸庞，漂亮的眼睛"
```

---

## 避坑指南

| ❌ 避免 | ✅ 替代 |
|--------|--------|
| "美丽"、"帅气" 等主观词 | 具体描述面部特征、比例 |
| 模糊的颜色描述 | 使用具体颜色词："深黑色"、"丹凤眼" |
| 忽略材质描述 | 明确服装材质："丝绸道袍"、"玉带" |
| 过长的无结构句子 | 分段描述不同部位 |
| "高质量"、"精美" 等空泛词 | 具体描述材质、光影、分辨率要求 |

## 与其他规范的关系

| 规范文件 | 关系 |
|----------|------|
| `character.md` | 角色性格、背景设定 |
| `portrait.md`（本文件） | 角色外观、图片生成提示词 |
| `script.md` | 剧本中引用角色外观 |

**使用流程**：
1. 先在 `character.md` 中定义角色性格和背景
2. 然后创建 `角色肖像/{角色名}_肖像提示词.md` 定义外观
3. 创作剧本时，从肖像文件中复制外观描述

---

## 使用说明

1. **创建新角色时**：使用 `/aim:portrait {角色名}` 命令自动生成肖像文件
2. **生成图片时**：复制英文提示词到 AI 绘画工具
3. **保持一致性**：每次创作新场次前，检查角色外观是否与此文件一致
4. **更新肖像**：如果角色外观发生变化（如受伤、换装），更新此文件并记录版本历史
5. **中文优化**：Qwen-Image 对中文渲染有独特优势，直接使用汉字描述
