# Style Keeper（风格守护者）

全局风格一致性管理，涵盖文笔、视觉、听觉、情感基调，确保像电影制片人一样掌控全片质量。

## 视觉圣经 (Visual Bible) 模板

### 1. 核心视觉 (Core Visuals)

*   **色调 (Color Palette)**：
    *   *Teal & Orange* (冷暖对比，电影感).
    *   *Monochrome* (黑白，艺术感).
    *   *Pastel* (粉嫩，梦幻/少女).
    *   *Cyberpunk Neon* (高饱和，霓虹).
    *   *Muted/Desaturated* (低饱和，压抑/现实).
*   **质感 (Texture)**：
    *   *Grainy / Noise* (胶片颗粒).
    *   *Smooth / Clean* (数字高清).
    *   *Gritty / Dirty* (肮脏，末世).
    *   *Ethereal / Glow* (发光，梦幻).

### 2. 摄影风格 (Cinematography)

*   **光影比 (Contrast Ratio)**：
    *   *High Key* (亮调，喜剧/日常).
    *   *Low Key* (暗调，惊悚/悬疑).
    *   *Chiaroscuro* (明暗对照，古典油画).

### 3. 美术指导 (Art Direction)

*   **布景风格**：极简主义 / 繁复主义 / 工业风 / 自然风。
*   **服装风格**：历史准确 / 现代混搭 / 未来主义 / 奇幻。

## 文笔风格指南 (Writing Style Guide)

*   **叙事节奏**：
    *   *Slow burn* (慢热，铺垫长).
    *   *Fast paced* (快节奏，反转多).
*   **语言特征**：
    *   *Hemingway-esque* (极简，白描).
    *   *Flowery / Poetic* (辞藻华丽，意象丰富).
    *   *Hard-boiled* (冷硬派，侦探风).
*   **对白风格**：
    *   *Sorkin-style* (语速快，信息量大).
    *   *Tarantino-style* (甚至有些啰嗦的闲聊，充满张力).

## 情感基调 (Tone & Mood)

| 情感 | 关键词 |
| :--- | :--- |
| **Melancholic** (忧郁) | Solitude, rain, blue, sad piano |
| **Whimsical** (异想天开) | Magic, colorful, quirky music |
| **Gritty** (写实粗砺) | Realistic, violence, handheld cam |
| **Epic** (史诗) | Grand scale, orchestral music, wide shots |

## 使用方式

```
请检查本场的视觉风格是否符合[风格名称]：
[分镜描述]
```

```
请对比这两段文笔的风格差异：
[文段A]
[文段B]
```

## 注意事项

- **风格漂移 (Style Drift)**：长篇创作中容易偏离初衷，需定期回溯《视觉圣经》。
- **平台适配**：不同 AI 平台对风格词的理解不同，需微调 Prompt。
- **一致性优先**：除了特意设计的反差，全集应保持统一基调。
