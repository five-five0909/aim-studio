# 剧本合法化

使用 AI 智能检查并修改剧本中的违规内容，使其符合 AI 视频生成平台的规定。

---

## 适用场景

- 检查剧本中是否存在违规内容（真人素材、版权角色、敏感内容等）
- 自动将违规内容修改为合规内容
- 修改角色名称使其"一听就像主角"
- 强化肖像描述让 AI 更容易理解

---

## 使用方法

### 检查剧本（只读，不修改）

```bash
/aim:legitimize --check
```

这会：
1. 读取 `spec/story/character.md` 角色设定
2. 读取 `spec/story/world.md` 世界观设定
3. 读取当前剧集的所有场景文件
4. 使用 AI 分析是否存在违规内容
5. 输出详细的检查报告

### 修复剧本（自动修改）

```bash
/aim:legitimize --fix
```

这会：
1. 先检查所有违规内容
2. 使用 AI 自动修改违规内容
3. 保存修改后的文件
4. 输出修改报告

---

## 违规类型及修改原则

### 1. 真人素材（高风险）

**格式**：`角色名【细节描述】`

| 原始 | 修改后 |
|------|--------|
| 刘德华 | 刘天霸【剑眉星目，身形挺拔，气宇轩昂】 |
| 周杰伦 | 周云飞【面容清秀，深情演唱】 |
| 网红脸 | 清秀面容【瓜子脸，大眼睛】 |

### 2. 版权角色（中风险）

**格式**：`角色名【细节描述】`

| 原始 | 修改后 |
|------|--------|
| 张无忌 | 张凌风【年纪轻轻内力深厚，剑眉星目，气度不凡】 |
| 钢铁侠 | 铁甲侠【身穿银色高科技战甲，胸口的能量环闪闪发光】 |
| 哈利波特 | 哈云【戴着圆框眼镜，手持魔杖，身披黑色巫师袍】 |

### 3. 敏感内容（中风险）

| 原始 | 修改后 | 说明 |
|------|--------|------|
| 血腥的屠杀 | 激烈的战斗 | 暴力 → 温和 |
| 自杀 | 离去 | 敏感 → 规避 |
| 赌博 | 比试 | 赌博 → 比赛 |

## 修改规则

### 角色名称修改

1. **同音/谐音替换**：保留原名的读音特点
2. **气质保持**：修改后的名字要符合人物设定
3. **主角感**：主角名字要"一听就像主角"
4. **原创优先**：避免任何知名人物的名字

### 肖像描述强化

**核心格式**：`角色名【细节描述】`

这种格式可以大大降低侵权概率，因为：
1. 方括号内的描述是详细的视觉特征
2. 不依赖任何真实人物的名字
3. AI 可以根据描述生成原创角色

**示例**：
| 原始 | 修改后 |
|------|--------|
| 刘德华 | 刘天霸【剑眉星目，身形挺拔，气宇轩昂，身穿黑色西装】 |
| 周杰伦 | 周云飞【面容清秀，留着利落短发，唱歌时深情款款】 |
| 网红脸 | 清秀面容【瓜子脸，大眼睛，鼻梁秀气嘴唇红润】 |

**强化规则**：
- "帅气" → "剑眉星目，鼻若悬胆，面容刚毅"
- "漂亮" → "柳眉杏眼，肤若凝脂，唇若点朱"
- "可爱" → "肉嘟嘟的小脸，大眼睛忽闪忽闪，嘴角笑起两个小酒窝"
- "强壮" → "身材魁梧，肌肉线条分明，浓眉大眼"

## 执行步骤

### 步骤 1：读取剧本文件

首先读取需要检查的文件：

```bash
# 读取角色设定
cat .aim-studio/spec/story/character.md

# 读取世界观设定
cat .aim-studio/spec/story/world.md

# 读取当前剧集
ls -la .aim-studio/tasks/
cat .aim-studio/tasks/EP01/*.md
```

### 步骤 2：AI 检查

使用 AI 分析内容，查找以下违规：

1. **真人素材**：明星、演员、网红、真实照片等
2. **版权内容**：金庸小说角色、漫威、哈利波特等受版权保护的内容
3. **敏感内容**：暴力、血腥、政治、宗教等

### 步骤 3：输出报告

输出格式：

```
📋 剧本合规性检查报告

【角色设定】spec/story/character.md
  ✅ 无违规

【世界观设定】spec/story/world.md
  ⚠️ 发现违规：
  - 版权：金庸 → 修改为原创角色"金玄"
  - 敏感："血腥战斗" → 改为"激烈对决"

【场景文件】
  EP01/场景1.md
    ✅ 无违规
  EP01/场景2.md
    ⚠️ 发现违规：
    - 版权："张无忌" → 修改为"张凌风"
    - 真实人物："网红脸" → 改为"清秀面容"
```

### 步骤 4：自动修复（如果使用 --fix）

对每个违规内容进行修改：

1. 角色名称替换
2. 肖像描述强化
3. 敏感内容温和化

修改后保存文件，并输出修改摘要。

## 注意事项

1. **API Key**：使用此命令需要配置 OpenAI API Key
   ```bash
   # 设置环境变量
   export OPENAI_API_KEY=your-api-key
   ```

2. **备份建议**：修复前建议备份原始文件

3. **审查修改**：AI 修改后建议人工审查确认

4. **多次执行**：可以多次执行直到无违规

---

## 相关命令

| 命令 | 用途 |
|------|------|
| `/aim:check-story` | 检查剧情一致性 |
| `/aim:export` | 导出视频提示词 |
| `/aim:story` | 开始创作 |

---

## 工作流程

```
1. /aim:story              → 创作剧本
2. /aim:legitimize --check → 检查是否有违规
3. /aim:legitimize --fix   → 自动修复违规内容
4. /aim:check-story        → 再次检查剧情一致性
5. /aim:export            → 导出视频提示词
```
