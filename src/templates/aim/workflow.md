## 快速开始

### 步骤 0：初始化项目（首次使用）

```bash
# 检查是否已初始化
aim status

# 如果未初始化，运行：
aim init
```

### 步骤 1：准备小说原文

将小说原文存放在 `.aim-studio/materials/` 目录下：

```
.aim-studio/materials/
├── 原著.txt          # 小说原文
├── 章节1.txt         # 分章节文件（可选）
└── ...
```

### 步骤 2：开始创作

使用斜杠命令开始创作：

```
/aim:story    # 漫剧创作模式
```

## 工作流概述

### 核心原则

1. **先读后写** - 理解上下文后再开始创作
2. **遵循规范** - 必须阅读 `.aim-studio/spec/story/` 规范
3. **增量创作** - 一次完成一个剧集
4. **及时记录** - 完成后立即更新上下文摘要
5. **保持一致** - 角色外观、场景风格必须一致

### 文件系统

```
.aim-studio/
├── workflow.md           # 本文档
├── spec/                 # 创作规范
│   └── story/            # 漫剧规范
│       ├── script.md     # 剧本与分镜规范
│       ├── character.md  # 角色设定规范
│       └── world.md      # 世界观设定规范
├── workspace/            # 工作区
│   └── {项目名}/         # 每个项目一个目录
│       ├── 全局上下文.txt
│       ├── 项目配置.md
│       └── 第1集_*/      # 剧集目录
├── materials/            # 小说原文
└── tasks/                # 任务追踪
```

## 创作流程

### 1. 准备阶段

```bash
# 1. 阅读创作规范
cat .aim-studio/spec/story/script.md

# 2. 阅读小说原文
cat .aim-studio/materials/原著.txt

# 3. 提取角色特征
# 使用 /aim:story 命令自动提取
```

### 2. 创作阶段

```
创作流程：
1. 提取角色特征 → 完善 character.md
2. 设定世界观 → 完善 world.md
3. 分章改编 → 生成每集剧本
4. 场次拆分 → 生成场次文件
5. 生成封面 → 使用 /aim:visualize
```

### 3. 输出阶段

每集输出结构：

```
第{集数}集_{中文标题}/
├── 剧本.md              # 完整剧本
├── 场次1.txt            # 可粘贴到 Seedance
├── 场次2.txt
├── ...
└── 上下文摘要.txt       # 本集结尾状态
```

### 4. Seedance 2.0 Prompt 格式

每个场次文件采用六要素结构：

```markdown
【主体描述】
角色外观、服装、体型、年龄、声音特征

【动作与表演】
具体动作描述，包含情绪强度和动作节奏

【环境与氛围】
场景地点、时间、天气、光线、氛围关键词

【镜头语言】
运镜方式、景别、特殊效果、节奏

【音频设计】
人声、环境音、音乐

【风格影调】
整体视觉风格、色调、参考作品

【剧本内容】
对白和动作描写

【封面图片提示词】
封面图片生成提示词
```

## 文件说明

### 1. spec/ - 创作规范

**用途**：文档化的创作标准

**结构**：
```
spec/story/
├── script.md     # 剧本与分镜规范（Seedance 2.0 优化）
├── character.md  # 角色设定规范
└── world.md      # 世界观设定规范
```

**何时更新**：
- 发现新的创作模式
- 修复问题后需要补充规范
- 建立新的约定

### 2. workspace/ - 工作区

**用途**：存放创作输出

**结构**：
```
workspace/{项目名}/
├── 项目配置.md          # 视频格式配置
├── 全局上下文.txt       # 角色设定、世界观
├── 使用说明.md          # 使用说明
├── 第1集_*/             # 剧集目录
└── ...
```

### 3. materials/ - 小说原文

**用途**：存放小说原文

**结构**：
```
materials/
├── 原著.txt             # 完整原文
├── 章节1.txt            # 分章节文件（可选）
└── ...
```

## 最佳实践

### ✅ 应该做

1. **创作前**：
   - 阅读 `.aim-studio/spec/story/` 规范
   - 阅读小说原文，提取角色特征

2. **创作中**：
   - 遵循 Seedance 2.0 Prompt 六要素结构
   - 保持角色外观、场景风格一致
   - 每个场次都包含封面图片提示词

3. **创作后**：
   - 使用 `/aim:check-story` 检查剧情逻辑
   - 更新上下文摘要
   - 使用 `/aim:finish-work` 完成工作

### ❌ 不应该做

1. **不要**跳过阅读规范
2. **不要**忽略音频设计（Seedance 2.0 核心能力）
3. **不要**使用空泛词（"高质量"、"4K"）
4. **不要**让角色外观在不同场次间不一致
5. **不要**忘记更新上下文摘要

## 常用命令

### 斜杠命令

| 命令 | 用途 |
|------|------|
| `/aim:start` | 通用模式开始工作 |
| `/aim:story` | 漫剧创作模式 |
| `/aim:visualize` | 生成图片提示词 |
| `/aim:export` | 导出创作内容 |
| `/aim:check-story` | 剧情逻辑检查 |
| `/aim:finish-work` | 结束工作并生成日志 |

### CLI 命令

```bash
aim init              # 初始化项目
aim update            # 更新模板
aim status            # 查看状态
```
